# Data Analyst Agent

This project implements a Data Analyst Agent as a Python script (`data_analyst_agent.py`). The agent can upload various document types, analyze data, answer questions, and generate visualizations. It uses the "meta-llama/Llama-4-Maverick-17B-128E-Instruct-FP8" model from Together.ai for its core intelligence.

## Features

- Supports file uploads for: `.txt`, `.docx`, `.pdf`, `.csv`, `.xlsx`, and image files (`.png`, `.jpg`, etc. for OCR).
- Extracts content from these files (text, tabular data, OCR for images).
- Generates an automatic summary of the uploaded data.
- Answers user questions about the loaded data, maintaining conversation context.
- Performs data analysis:
    - For tabular data (CSV/Excel): Generates and executes Python (Pandas) code based on user requests.
    - For text data: Uses the LLM to perform analysis like summarization or information extraction.
- Generates visualizations:
    - For tabular data: Generates and executes Python (Matplotlib/Seaborn) code to create plots, saving them as `plot.png`.

## Setup

1.  **Clone the repository or download the files.**

2.  **Install Python dependencies:**
    Make sure you have Python 3.7+ installed. Then, install the required libraries using pip:
    ```bash
    pip install -r requirements.txt
    ```

3.  **Install Tesseract OCR (for image analysis):**
    The agent uses `pytesseract` for extracting text from images. This requires Google's Tesseract OCR engine to be installed on your system.
    -   **Windows:** Download and run the installer from [Tesseract at UB Mannheim](https://github.com/UB-Mannheim/tesseract/wiki). Make sure to add Tesseract to your system PATH or note the installation location for `pytesseract`.
    -   **Linux (Ubuntu/Debian):**
        ```bash
        sudo apt-get update
        sudo apt-get install tesseract-ocr
        ```
    -   **macOS:**
        ```bash
        brew install tesseract
        ```
    You might need to configure `pytesseract` to point to your Tesseract installation if it's not in the PATH. Refer to the `pytesseract` documentation if you encounter issues.

4.  **Set Together.ai API Key:**
    The agent requires an API key from [Together.ai](https://www.together.ai/) to use the "meta-llama/Llama-4-Maverick-17B-128E-Instruct-FP8" model.
    -   Obtain your API key from your Together.ai account.
    -   **Recommended:** Set it as an environment variable named `TOGETHER_API_KEY`.
        -   **Linux/macOS:** `export TOGETHER_API_KEY='your_api_key_here'`
        -   **Windows (PowerShell):** `$env:TOGETHER_API_KEY='your_api_key_here'`
    -   The script (`data_analyst_agent.py`) includes a fallback API key for convenience. However, if this key is revoked or rate-limited, you will need to use your own by setting the environment variable. Using your personal API key via the environment variable is the most robust and secure method.

## Running the Script

1.  Ensure all setup steps are complete:
    - Python dependencies installed (see `requirements.txt`).
    - Tesseract OCR installed if image analysis is needed.
    - `TOGETHER_API_KEY` environment variable is set with your API key.
2.  Navigate to the project directory in your terminal.
3.  Run the script using Python:
    ```bash
    python data_analyst_agent.py
    ```
4.  The script will:
    - Create sample files (`sample.txt`, `sample.csv`, etc.) in the current directory.
    - Instantiate the Data Analysis Agent.
    - Perform a series of demonstrations:
        - Uploading each sample file type.
        - Asking questions about the data.
        - Performing data analysis.
        - Generating visualizations (e.g., `plot.png` will be saved in the current directory).
    - Print output to the console, including summaries, answers, analysis results, and paths to saved plots.

## Model Used

This agent exclusively uses the `meta-llama/Llama-4-Maverick-17B-128E-Instruct-FP8` model from Together.ai as per the requirements.

## Structure

-   `data_analyst_agent.py`: The main Python script containing all the code and demonstrations.
-   `requirements.txt`: A list of Python dependencies.
-   `README.md`: This file.
-   `sample.*`: Sample files generated by the script for demonstration (e.g., `sample.txt`, `sample.csv`, `plot.png`). These are created when you run the script.
